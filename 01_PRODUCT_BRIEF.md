# Product Brief – InternshipTracker

## One-sentence description

InternshipTracker is a SwiftUI iOS app that helps students organize, track, and follow up on internship and junior job applications.

## Target users

- Computer engineering students
- University students searching for internships
- Junior developers tracking applications
- Students who apply to many companies and lose track of status/deadlines

## Problem

Students often apply to many companies through different platforms. They forget:

- where they applied
- which role they applied for
- application status
- follow-up dates
- interview dates
- company notes
- links and contact information

## Solution

A simple mobile tracker that keeps every application in one place and reminds the user when they need to follow up.

## MVP promise

“Track every internship application from draft to offer.”

## Main value

- Reduces stress during internship search
- Gives visibility over the application process
- Helps students act professionally with follow-ups
- Creates a useful portfolio project for the developer

## Design principles

- Fast to add an application
- Easy to scan status
- Native iOS look
- No account required
- No unnecessary complexity

## Success criteria for MVP

The MVP is successful if the user can:

1. Add an application
2. View applications in a searchable list
3. Filter by status
4. Edit an application
5. Delete an application
6. See dashboard stats
7. Set an optional follow-up reminder
